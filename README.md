# Scout Application

A comprehensive Java-based web application built with Spring MVC, MyBatis, and Oracle Database.

## 🚀 Live Demo

**Live Demo**: [Scout Application](https://scout-application.onrender.com)

## 🛠️ Technologies Used

- **Backend**: Java 11, Spring MVC 5.3.27
- **Database**: Oracle Database with MyBatis
- **Frontend**: JSP, JSTL, HTML, CSS, JavaScript
- **Build Tool**: Maven
- **Other**: JSON Simple, Lombok, Log4j

## 📋 Features

- User authentication and authorization
- Database integration with Oracle
- RESTful API endpoints
- Email functionality
- Form validation
- Responsive web interface

## 🏗️ Project Structure


## 🚀 Getting Started

### Prerequisites
- Java 11 or higher
- Maven 3.6+
- Oracle Database

### Installation
1. Clone the repository
2. Configure database connection in `src/main/resources/`
3. Run `mvn clean package`
4. Deploy the WAR file to a servlet container
